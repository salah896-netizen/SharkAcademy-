# Architecture

Generated by `research/architecture/map.cjs`. Do not edit by hand.

The app is plain browser JavaScript with no build step. Every file in `dist/` shares one global scope and loads in the order below; `boot.js` loads last and draws the first screen once everything exists.

Later files extend earlier features in one of three explicit ways, each a plain list owned by the base file:

- **Sources** (`…Sources`): picture lookups. Each source is asked in turn; the first with an answer wins. Later files add theirs to the front.
- **Steps** (`…Steps`): after the base function draws its screen, each step runs in load order and adds to it.
- **Layers** (`…Layers`): each layer gets the call first, with a `next` to carry on; it can answer itself, pass it on, or change the result. Later files add theirs to the front.

A few older functions are still **wrapped** by reassignment (`const preX = x; x = function () { … preX() … }`), listed further down. There, order matters and the last wrapper runs first.
