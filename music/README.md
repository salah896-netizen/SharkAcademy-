# Original adventure music

Six original instrumental loops composed for Haytham’s Shark Academy. Run `compose.py` with Python and NumPy to regenerate the stereo WAV masters. The app uses AAC versions in `dist/audio/`. No third-party music or recordings are used.

Each learning area has its own motif and instrumentation: sunken-city exploration, pirate treasure, deep-ocean discovery, a gentle writing lagoon, a lantern-lit story grotto, and a treasure anchorage. Music starts after a tap, crossfades between areas, softens while Milo speaks, and pauses in the background. The music button and parent volume slider control playback.
