# Voice batch 1 (24 October 2026)

274 ElevenLabs clips (eleven_v4, voices from the handover voice map), then 14 unused race lines removed:
- Willa: lines for the new reading and listening lessons (questions, reactions, hints and picture names).
- Tap lines for all five friends.
- Celebrations (Willa and Milo) and all race lines in each racer's or helper's voice.
- The 42 Jolly Phonics sounds in `dist/audio/voice/sounds/`.

How it works:
- `build-lines.cjs` extracts the exact lines from the app.
- `generate.py` calls the API. It is resumable and reads the key from a local file outside the repo.
- `qa.py` checks every clip (length, silence, cut-offs, stray vowels in hiss sounds) and writes `dist/voice-manifest.js`.

At runtime, `dist/voice-clips.js` plays a recording whenever one exists for the character and text, sentence by sentence. Otherwise the device voice speaks as before.

The parent chose the "Mmmm!" version of the m sound as the best so far; it could be replaced with a family recording. The other sounds should get a listen with the school's sound cards. Any clip can be regenerated by deleting its file and rerunning `generate.py`.

No API key or credentials are stored in this repository.

## Family recordings (29 October 2026)
The parent recorded the 12 quick sounds from "Shark Academy phonics sounds to record" (b, ch, ck, d, g, j, m, p, qu, w, x, y) on an iPhone. Each recording has one sound, some talking, then three clean repeats. One clean repeat was cut from the last three (the one closest to the median length), trimmed with an 80 ms lead-in and a 150 ms silent tail, high-passed at 70 Hz, levelled to an active loudness of -21 dB with peaks capped at -4 dBFS (the generated consonants were 10-20 dB quieter than the vowels), and saved as 128 kbps mono MP3.
- They live in `dist/audio/voice/sounds/family/`, a new path on purpose: the iPad keeps recordings in a media cache across updates (`haytham-media-v1`, cache-first), so reusing the old file names would have kept the old generated sounds on Haytham's iPad.
- `voice-manifest.js` points those 12 sounds at `family/`. If `qa.py` ever regenerates the manifest, keep those entries.
- The full original recordings stay on the parent's Mac (`Shark Academy Voices/Recording/`) and are not in this repository.
- The grown-ups' area lists all 42 sounds under "Phonics sounds", tap to hear, with family recordings marked.
