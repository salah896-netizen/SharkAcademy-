# Voice batch 1 (24 October 2026)

274 ElevenLabs clips (eleven_v4, voices from the handover voice map), then 14 unused race lines removed:
- Willa: lines for the new reading and listening lessons (questions, reactions, hints and picture names).
- Tap lines for all five friends.
- Celebrations (Willa and Milo) and all race lines in each racer's or helper's voice.
- The 42 Jolly Phonics sounds in `dist/audio/voice/sounds/`.

How it works:
- `build-lines.cjs` extracts the exact lines from the app.
- `generate.py` calls the API. It is resumable and reads the key from a local file outside the repo.
- `qa.py` checks every clip (length, silence, cut-offs, stray vowels in hiss sounds) and writes `dist/voice-manifest.js`.

At runtime, `dist/voice-clips.js` plays a recording whenever one exists for the character and text, sentence by sentence. Otherwise the device voice speaks as before.

The parent chose the "Mmmm!" version of the m sound as the best so far; it could be replaced with a family recording. The other sounds should get a listen with the school's sound cards. Any clip can be regenerated by deleting its file and rerunning `generate.py`.

No API key or credentials are stored in this repository.
